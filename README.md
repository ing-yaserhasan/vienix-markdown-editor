# محرر ومنصة كتب فينيكس ماركداون | Vienix Markdown Editor

نظام ومحرر ماركداون متقدم واحترافي يدعم الكتابة من اليمين إلى اليسار (RTL)، مصمم خصيصاً للكتّاب، المؤلفين، والمطورين لإنتاج وتنسيق وطباعة الكتب والمستندات بدقة متناهية.

---

## 🌟 الميزات والمواصفات الرئيسية

- 📖 **نظام إخراج وتوزيع صفحات الكتاب (Book Pagination System)**:
  - تقسيم فيزيائي دقيق للصفحات وفق معايير مقاسات الطباعة (A4 / Letter).
  - منع تشتت الأسطر والقوائم المبتورة (Widow & Orphan control).
  - فواصل صفحات ذكية (مثل `---pagebreak---` أو `\newpage`).
  - خيارات متعددة لتنسيق أرقام الصفحات (صفحة X من Y، صفحة X، أو رقم مجرد) مع خيارات المحاذاة.

- 📦 **نظام الحجرات التخزينية الثمانية (8 Modular Storage Chambers)**:
  - إدارة 8 مسودات أو فصول مستقلة بالكامل داخل المتصفح.
  - دعم التسميات المخصصة لكل حجرة.
  - إحصائيات حية للحفظ ووقت التعديل.

- 🔍 **نظام المطابقة المباشرة ومقارنة الفصول (Live Chapter Diff & Matcher)**:
  - مقارنة أي حجرة أو نص خارجي مع الحجرة النشطة بنقرة زر لمعاينة الفروقات قبل الدمج.

- 📚 **تجميع وطباعة الكتاب كاملاً (Master Book Compiler)**:
  - دمج كافة الفصول المكتوبة في الحجرات بترتيبها في مستند موحد جاهز للطباعة أو التصدير بصيغة PDF فوراً.

- 🎨 **تخصيص كامل وواجهة احترافية**:
  - تحكم متقدم بحجم وهوامش الخطوط، التباعد بين السطور، ألوان التمييز، والوضع الليلي/النهاري.
  - توافق وتجاوب ممتاز مع الهواتف الذكية والشاشات الكبيرة.
