# قائمة التحقق والقبول (Acceptance Checklist)

> تستخدم هذه القائمة من قبل أي مطور أو وكيل ذكاء اصطناعي (Agent) للتحقق الدقيق من اكتمال وجودة ومطابقة تطبيق Android Native لتطبيق الويب الأصلي قبل اعتماده.

---

## 1. محرر النصوص (Editor Acceptance)

- [ ] **الكتابة والإدخال**: الكتابة باللغة العربية والإنجليزية سلسة وبدون أي تأخير (No Latency) في Compose `TextField`.
- [ ] **التلوين الصرفي الحي (Syntax Highlighting)**: تمييز العناوين باللون المميز، والأكواد بخلفية مخصصة، والروابط بلون الرابط أثناء الكتابة في المحرر.
- [ ] **الحفظ التلقائي (Auto-save)**: حفظ المستند تلقائياً في Room بعد توقف المستخدم عن الكتابة لمدة 400ms مع وميض خفيف لحالة الحفظ "تم الحفظ".
- [ ] **التراجع والإعادة (Undo/Redo)**: أزرار التراجع والإعادة تعمل بشكل صحيح وتحتفظ بلقطات التحرير.
- [ ] **شريط أدوات التنسيق (Toolbar)**:
  - [ ] تطبيق العناوين H1 إلى H6 بشكل سليم في بداية السطر.
  - [ ] إضافة التنسيقات (غامق، مائل، خط بالمنتصف، رابط، كود) حول النص المحدد أو إدراج رموزها عند موضع المؤشر.
  - [ ] إدراج الجداول، القوائم النقطية والرقمية، واقتباسات النصوص.
  - [ ] دعم مربعات المهام `- [ ]` وعكس حالتها عند النقر.
- [ ] **إحصاءات النص (Status Bar)**: حساب دقيق ومباشر لعدد الكلمات، عدد الأحرف، ووقت القراءة بالدقائق.

---

## 2. المعاينة وتفسير الماركداون (Preview Acceptance)

- [ ] **تفسير الماركداون**: دعم كامل لـ CommonMark و GFM (GitHub Flavored Markdown):
  - [ ] العناوين بجميع مستوياتها مع هوامش صحيحة.
  - [ ] الجداول التنسيقية مع حدود واضحة وتوافق مع الشاشة.
  - [ ] كتل الأكواد مع تمييز لوني (Syntax Highlighting) وخط برمجي مناسب.
  - [ ] الروابط التفاعلية وقابليتها للفتح في المتصفح الخارجي.
- [ ] **مخططات Mermaid**: تصيير المخططات البيانية (Flowcharts, Sequence Diagrams, Gantt) بشكل صحيح دون أخطاء.
- [ ] **التمرير المتزامن (Sync Scroll)**: عند تفعيل وضع الشاشة المنقسمة على الأجهزة اللوحية، يتزامن تمرير المحرر مع المعاينة بنعومة.

---

## 3. الحجرات والمستندات (Chambers & File Management)

- [ ] **إدارة الحجرات (Workspaces)**:
  - [ ] إنشاء حجرة جديدة باسم ولون وأيقونة مخصصة.
  - [ ] تعديل بيانات الحجرة أو حذفها مع معالجة المستندات التابعة لها.
  - [ ] التبديل الفوري بين الحجرات مع حفظ حالة المستند النشط.
- [ ] **إدارة المستندات**:
  - [ ] إنشاء مستند جديد، حذف مستند، أو نقله إلى سلة المهملات.
  - [ ] تفضيل المستند (Favorite) وتثبيته في الأعلى (Pin).
  - [ ] البحث الفوري في عناوين ومحتويات المستندات مع إبراز النتائج.

---

## 4. التصميم وتجربة المستخدم (UI & UX Acceptance)

- [ ] **تطابق الألوان والمظهر**:
  - [ ] دعم النمطين الفاتح (Light) والداكن (Dark) بنفس درجات الألوان المحددة في `DESIGN_TOKENS.md`.
  - [ ] نعومة حواف العناصر (Border Radius 6dp/10dp/14dp).
  - [ ] الظلال والارتفاعات مطابقة للأصل.
- [ ] **دعم اللغة العربية والـ RTL**:
  - [ ] اتجاه الشاشة والقوائم والأدراج من اليمين إلى اليسار تلقائياً.
  - [ ] تطبيق الخطوط العربية (Tajawal / Amiri / Cairo) بشكل نظيف مع الحفاظ على ترابط الحروف.
- [ ] **الاستجابة للشاشات (Responsiveness)**:
  - [ ] تجربة متناسقة ومريحة على شاشات الهواتف الرأسية (Portrait).
  - [ ] استغلال العرض المنقسم التلقائي على الأجهزة اللوحية (Tablets) والشاشات الأفقية.

---

## 5. النسخ الاحتياطي والتصدير (Backup & Export Acceptance)

- [ ] **تصدير واستيراد النسخة الاحتياطية**: تصدير كل المستندات والحجرات كملف JSON واستعادتها دون فقدان أي حقل.
- [ ] **تصدير كـ Markdown**: تنزيل الملف بصيغة `.md`.
- [ ] **تصدير كـ PDF**: توليد ملف PDF منسق وجاهز للطباعة والمشاركة عبر محرك الطباعة في أندرويد.
- [ ] **تصدير الكتاب (Book Export)**: إمكانية تجميع فصول متعددة في مستند كتاب واحد متصل مع فهرس محتويات.
