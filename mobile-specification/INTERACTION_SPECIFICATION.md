## 1. محرر النصوص (Editor Interactions)

### 1.1 الكتابة والتحديث الحي
- **الحدث**: `input` أو `keyup` على عنصر `#editor-textarea`.
- **المعالجة**:
  - حساب عدد الكلمات (Word Count)، الأحرف (Character Count)، ووقت القراءة التقديري (Reading Time) وتحديث شريط الحالة فوراً.
  - تشغيل آلية المؤقت للحفظ التلقائي المؤجل (Debounced Auto-save) بفترة تأخير 400ms إلى 800ms.
  - إرسال المحتوى لمفسر الماركداون لتحديث شاشة المعاينة الحية (Live Preview) في الوقت الحقيقي إذا كان وضع المعاينة المزدوجة مفعلًا.

### 1.2 التراجع والإعادة (Undo / Redo)
- يدعم مكدس تراجع مخصص في JavaScript (Stack-based Undo/Redo) يحفظ لقطات من النص عند التوقف عن الكتابة، بالإضافة إلى التراجع الافتراضي للمتصفح.
- اختصارات: `Ctrl + Z` للتراجع، و `Ctrl + Y` أو `Ctrl + Shift + Z` للإعادة.

### 1.3 اختصارات التنسيق السريع (Formatting Shortcuts)
- **غامق (Bold)**: `Ctrl + B` -> يحيط النص المحدد بـ `**نص**`.
- **مائل (Italic)**: `Ctrl + I` -> يحيط النص بـ `*نص*`.
- **رابط (Link)**: `Ctrl + K` -> يفتح نافذة إضافة رابط أو يدرج `[نص](url)`.
- **عنوان (Heading)**: `Ctrl + H` أو أزرار H1-H6 -> يضيف بادئة `#` في بداية السطر.
- **قائمة نقطية / رقمية**: إدراج `- ` أو `1. ` مع دعم الضغط على Enter في نهاية العنصر للانتقال التلقائي للسطر التالي مع ترقيم تلقائي.
- **مربعات الاختيار (Checkboxes)**: `- [ ] `، والنقر على المربع في المعاينة يعكس حالته تلقائياً في النص الأصلي في المحرر.

### 1.4 التعامل مع Tab والتنسيق التلقائي
- الضغط على `Tab` يدرج مسافتين أو 4 مسافات (حسب الإعدادات) ولا يخرج التركيز من المحرر.
- الضغط على `Shift + Tab` يلغي المسافة البادئة (Unindent).

## 2. شريط الأدوات الرئيسي والعائم (Toolbar & Floating Dock)

### 2.1 شريط الأدوات العلوي
- كل زر يمتلك `id` وحالة `active` أو `disabled`.
- الأزرار تتفاعل بـ Hover و Active states.
- زر تبديل وضع العرض (View Modes):
  - **محرر فقط (Editor Only)**: إخفاء المعاينة بنسبة عرض 100% للمحرر.
  - **معاينة فقط (Preview Only)**: إخفاء المحرر وعرض الماركداون المفسر.
  - **عرض منقسم (Split View)**: تقسيم الشاشة إلى لوحين بنسبة قابلة للسحب.
- زر وضع التركيز / زن (Zen Mode): يخفي جميع أشرطة الأدوات والقوائم ليبقى النص فقط.

### 2.2 شريط السحب لتغيير الحجم (Splitter Resizing Drag)
- شريط المقسم الرأسي بين المحرر والمعاينة (`#resizer` أو `#gutter`):
  - عند الضغط مع السحب (`mousedown` + `mousemove`) يتم تعديل عرض المحرر والمعاينة كنسب مئوية `flex-basis` ديناميكياً.
  - حفظ النسبة المفضلة في التخزين المحلي لاسترجاعها عند إعادة الفتح.

## 3. التمرير المتزامن (Synchronized Scrolling)

- عند تمرير المحرر (`scroll` event on Editor):
  - حساب النسبة المئوية للموضع الرأسي: `ratio = scrollTop / (scrollHeight - clientHeight)`.
  - تطبيق نفس النسبة تلقائياً على لوحة المعاينة: `preview.scrollTop = ratio * (preview.scrollHeight - preview.clientHeight)`.
- العكس صحيح عند تمرير المعاينة (مع flag لمنع الـ Infinite Scroll Loop).

## 4. نظام الحجرات والمستندات (Chambers & Document Management)

### 4.1 اختيار وتبديل الحجرة
- النقر على حجرة في القائمة الجانبية:
  - حفظ التغييرات الحالية للمستند النشط تلقائياً.
  - قراءة قائمة المستندات التابعة للحجرة من IndexedDB.
  - تعيين أول مستند كنشط أو فتح آخر مستند مفتوح داخل الحجرة.
  - إطلاق تأثير انتقالي خفيف لتحديث القائمة.

### 4.2 إنشاء / تعديل / حذف حجرة
- **إنشاء**: نافذة منبثقة تطلب (الاسم، الأيقونة، اللون).
- **إعادة تسمية**: تعديل مباشر (Inline editing) أو نافذة حوارية.
- **حذف**: تأكيد الحذف؛ نقل مستنداتها إلى الحجرة الافتراضية أو سلة المهملات.

## 5. النوافذ المنبثقة والقوائم الحوارية (Modals & Dialogs)

### 5.1 سلوك فتح وإغلاق النوافذ
- فتح أي نافذة يضع طبقة تعتيم خلفية (`modal-backdrop`).
- الإغلاق يتم عبر:
  1. زر الإغلاق `×` في الزاوية العلوية.
  2. النقر خارج محتوى النافذة (على الـ Backdrop).
  3. الضغط على مفتاح `Esc` في لوحة المفاتيح.
- قفل التمرير للخلفية عند فتح النافذة لمنع تمرير الصفحة الرئيسية.

### 5.2 النوافذ الرئيسية:
- **نافذة الإعدادات (Settings Modal)**: علامات تبويب (عام، خطوط، مظهر، متقدم). الحفظ فوري في التخزين المحلي وتطبيق التغييرات على الفور.
- **نافذة تصدير الكتاب (Book Export Modal)**: اختيار المستندات، ترتيب الفصول بالسحب والإفلات، توليد فهرس المحتويات (TOC)، واختيار صيغة التصدير (PDF / EPUB / HTML).
- **نافذة النسخ الاحتياطي (Backup/Restore)**: تصدير JSON كامل لكل البيانات أو استيراده مع شريط تقدم وفحص صحة البيانات (Integrity Check).
- **نافذة البحث والاستبدال (Find & Replace)**: بحث نصي أو Regex، تحديد النتائج، التنقل بينها (Next/Prev)، والاستبدال الفردي أو الجماعي (Replace All).

## 6. استيراد وتصدير الملفات (Import & Export Interactions)

- **استيراد ملفات**: دعم السحب والإفلات (Drag and Drop) لملفات `.md` أو `.txt` مباشرة فوق المحرر لقراءتها عبر `FileReader API`.
- **تصدير سريع**:
  - تصدير كـ Markdown (`.md`): تنزيل ملف نصي مباشر.
  - تصدير كـ HTML جاهز: دمج التنسيق وأكواد CSS داخل قالب HTML مستقل.
  - تصدير كـ PDF: استدعاء نافذة الطباعة (`window.print()`) مع CSS مخصص `@media print`.

## 7. الميزات الخاصة والذكاء الاصطناعي (AI & Voice Interactions)

- **مساعد النطق الصوتي (TTS)**: قراءة النص العربي المحدد باستخدام Web Speech API مع أزرار تشغيل، إيقاف مؤقت، وإعادة ضبط السرعة.
- **محادثة الذكاء الاصطناعي (AI Assistant Dialog)**: نافذة تتيح إدخال أوامر للمساعدة في صياغة أو تلخيص أو تدقيق النص الماركداون مع حفظ مفتاح API في الإعدادات المحلية للمستخدم.
