## 1. تحرير الماركداون (Markdown Editing)

### 1.1 محرر النص الأساسي
- **الوصف:** حقل نصي (`textarea#markdown-input`) يقبل كتابة الماركداون.
- **الاتجاه الافتراضي:** RTL (قابل للتغيير من الإعدادات إلى LTR أو Auto).
- **الحفظ التلقائي:** يتم عند كل تغيير بعد debounce 200ms.
- **السلوك:** عند الكتابة → يُطلق `renderMarkdown()` → النتيجة تظهر فوراً في المعاينة.
- **الملف:** `rtlmd.js` — الدالة `setupEventListeners()` (سطر ~1952)

### 1.2 شريط الأدوات (Toolbar)
أزرار التنسيق الموجودة فعلاً في الشريط العلوي:

| الزر | الوظيفة | الدالة |
|------|---------|--------|
| **B** (عريض) | إدراج `**نص**` | `insertFormat('**', '**')` |
| **I** (مائل) | إدراج `*نص*` | `insertFormat('*', '*')` |
| **S** (يتوسطه خط) | إدراج `~~نص~~` | `insertFormat('~~', '~~')` |
| **H1, H2, H3** | إدراج عناوين | `insertHeading(1/2/3)` |
| قائمة نقطية | إدراج `- عنصر` | `insertList(false)` |
| قائمة رقمية | إدراج `1. عنصر` | `insertList(true)` |
| قائمة مهام | إدراج `- [ ] مهمة` | `insertTask()` |
| اقتباس | إدراج `> نص` | `insertQuote()` |
| كتلة كود | إدراج ` ```code``` ` | `insertCodeBlock()` |
| جدول | نافذة إدراج جدول مخصص | `insertTable()` → يفتح `insert-table-modal` |
| رابط | إدراج `[نص](رابط)` | `insertLink()` |
| صورة | إدراج `![وصف](رابط)` | `insertImage()` |
| خط فاصل | إدراج `---` | `insertHorizontalRule()` |
| إيموجي | لوحة إيموجي (3700+) | `toggleEmojiPicker()` |
| أسهم وأشكال | لوحة أسهم (41 شكلاً) | `toggleArrowPicker()` |

- **الملف:** `index.html` سطر 203–280، `rtlmd.js` دوال `insertFormat()`, `insertHeading()` إلخ.

## 2. المعاينة المباشرة (Live Preview)

### 2.1 تصيير الماركداون
- **المكتبة:** `marked.js` مع renderer مخصص.
- **الميزات المدعومة:** GFM (GitHub Flavored Markdown)، أسطر جديدة (`breaks: true`)، جداول، قوائم مهام.
- **أبعاد الصور المخصصة:** `![alt|450px](url)` أو `![alt](url =450x)`
- **الملف:** `rtlmd.js` دالة `initMarked()` سطر ~691

### 2.2 مخططات Mermaid
- **الأنواع المدعومة:** Flowchart، Sequence Diagram، Mindmap، Pie Chart
- **السلوك:** تُستخرج كتل mermaid قبل التحويل، ثم تُرسم بشكل غير متزامن مع كاش فوري (`mermaidSvgCache`).
- **أزرار تكبير/تصغير لكل مخطط:** `zoomSingleDiagram()`.
- **تحمل الأخطاء:** عند خطأ في الصياغة، يُعرض رسالة تنبيه عربية بدلاً من تعطل الصفحة.
- **الملف:** `rtlmd.js` دوال `initMermaid()`, `extractMermaidBlocks()`, `renderMermaidNodes()`

### 2.3 تلوين الأكواد (Syntax Highlighting)
- **المكتبة:** `Prism.js` مع سمة `prism-tomorrow`.
- **السلوك:** بعد كل رندر، يتم تلوين جميع كتل `<pre><code>` تلقائياً.
- **أزرار نسخ الكود:** تظهر فوق كل كتلة كود عبر `setupCodeCopyButtons()`.

### 2.4 التمرير المتزامن (Synchronized Scrolling)
- **الوصف:** عند التمرير في المحرر، تتحرك المعاينة بنفس النسبة والعكس.
- **قابل للإيقاف:** زر `toggleSyncScroll()` في شريط الأدوات.
- **التخزين:** `vienix_sync_scroll` في localStorage.
- **الملف:** `rtlmd.js` دوال `handleEditorScroll()`, `handlePreviewScroll()`

### 2.5 قوائم المهام التفاعلية
- **الوصف:** الضغط على checkbox في المعاينة يُحدّث نص الماركداون في المحرر مباشرة.
- **الملف:** `rtlmd.js` دالة `toggleTaskCheckboxInEditor()` سطر ~1138

### 2.6 المحافظة على الأسطر الفارغة
- **الوصف:** أسطر Enter الإضافية في المحرر تُعكس في المعاينة كمسافات رأسية حقيقية.

- **الوصف:** عند لصق صورة من الحافظة، تُضغط تلقائياً عبر Canvas وتُدرج في الماركداون.
- **الضغط:** `optimizeImageFile()` — يحوّل إلى WebP/JPEG بأبعاد أقصى 1280px وجودة 82%.
- **الملف:** `rtlmd.js` دالة `handleImagePaste()` سطر ~2256

### 14.2 سحب وإفلات (Drag & Drop)
- **نفس آلية الضغط والإدراج.
- **الملف:** `rtlmd.js` دالة `handleImageDrop()` سطر ~2306

### 14.3 رفع من الجهاز
- **عبر حقل مخفي** `image-upload-input` مع نفس آلية الضغط.

### 14.4 مرفقات الصور (VienixImages)
- **الوصف:** الصور الكبيرة تُخزن في IndexedDB بمعرّف فريد وتُشار إليها بـ `vienix-img://id`.
- **التنظيف التلقائي:** `cleanseMarkdownImages()` يحوّل أكواد Base64 الضخمة إلى مرفقات.
