## 1. التخطيط العام (Layout Structure)

التطبيق صفحة واحدة بتخطيط رأسي ثابت:

```
┌─────────────────────────────────────────────────┐
│  شريط الرأس (Header)                           │
├─────────────────────────────────────────────────┤
│  شريط الأدوات (Toolbar)                         │
├─────────────────────────────────────────────────┤
│  شريط الحجرات (Chambers Bar)                    │
├──────────────────────┬──────────────────────────┤
│                      │                          │
│   منطقة المحرر       │   خط فاصل    منطقة      │
│   (Editor Panel)     │   (Resizer)  المعاينة    │
│                      │              (Preview)   │
│                      │                          │
├──────────────────────┴──────────────────────────┤
│  شريط الحالة (Status Bar)                       │
└─────────────────────────────────────────────────┘
```

- **الاتجاه الأساسي:** RTL (`direction: rtl` على `html` و`body`).
- **الارتفاع:** `100vh` — يملأ كامل الشاشة بدون تمرير خارجي.
- **التطبيق مقسّم باستخدام Flexbox** (`#workspace` — `display: flex`).

## 3. شريط الأدوات (Toolbar)

- **العنصر:** `#toolbar`
- **الارتفاع:** ~36–42px
- **السلوك:** يختفي في الوضع الكلاسيكي وفي الموبايل يصبح قابلاً للتمرير الأفقي.

### أزرار الشريط (ترتيب فعلي من اليمين)
```
[H1][H2][H3] | [B][I][S] | [قائمة نقطية][قائمة رقمية][مهام] | [اقتباس][كود][جدول] | [رابط][صورة] | [خط فاصل] | [إيموجي][أسهم] | [نموذج][تصفير][لصق]
```

كل زر:
- **الأبعاد:** ~30×30px مع `padding: 4px 6px`
- **الشكل:** مدور بـ `border-radius: var(--radius-sm)` (6px)
- **التأثير:** `hover` → خلفية `var(--bg-hover)` مع `transition: 0.15s`
- **الأيقونات:** كلها SVG inline (لا صور خارجية)

## 4. شريط الحجرات (Chambers Bar)

- **العنصر:** `#chambers-bar`
- **الارتفاع:** ~36–40px
- **التخطيط:** `display: flex` مع `overflow-x: auto` وأسهم تنقل يسار/يمين.

### عناصر الشريط
```
[سهم ←] [حجرة 1] [حجرة 2] ... [حجرة 7] [□ حجرة فارغة] [حالة الحفظ] [سهم →]
```

كل زر حجرة:
- **الشكل العادي:** خلفية شفافة، نص `var(--text-muted)`
- **الحجرة النشطة:** خلفية `var(--accent-light)`, نص `var(--accent-color)`, حافة سفلية ملونة
- **الحجرة الفارغة المتقطعة:** إطار متقطع `border: 1.5px dashed` + أيقونة `+`
- **مؤشر الحجرة الممتلئة:** نقطة صغيرة ملونة بجانب الرقم
- **قائمة سياقية:** right-click يفتح `chamber-context-menu`

### شارة حالة الحفظ
- **العنصر:** `#save-status`
- **الحالات:**
  - `saved` → "✓ محفوظ" (أخضر)
  - `saving` → "جارٍ الحفظ..." (أصفر/كهرماني)
  - `error` → خطأ (أحمر)

## 5. منطقة المحرر (Editor Panel)

- **العنصر:** `#panel-editor` → `#editor-container` → `#markdown-input`
- **النوع:** `<textarea>` مع `dir="rtl"` افتراضياً
- **الخط:** `var(--font-mono)` — Fira Code / JetBrains Mono
- **حجم الخط الافتراضي:** 15px (قابل للتعديل 12-24px)
- **اللون:** `var(--text-primary)` على خلفية `var(--bg-surface)`
- **التفاف:** `word-wrap: break-word` (قابل للإيقاف)
- **Placeholder:** "ابدأ الكتابة هنا بلغة الماركداون..."

### الشريط العائم (Floating Dock)
يظهر داخل منطقة المحرر — لوحة صغيرة قابلة للسحب:
```
[مقبض السحب ⠿] [تراجع ↩] [إعادة ↪] [تصفير 🗑] [لصق+ 📋]
```
- **العنصر:** `#floating-dock-wrapper`
- **الموضع:** `position: absolute` — قابل للسحب بـ `draggable handle`
- **الشكل:** خلفية `var(--bg-surface-elevated)` مع `backdrop-filter: blur(12px)`, `border-radius: 10px`, ظل `var(--shadow-md)`

## 7. منطقة المعاينة (Preview Panel)

- **العنصر:** `#panel-preview` → `#preview-content`
- **الاتجاه:** RTL
- **الخط الافتراضي:** `var(--font-arabic)` — Tajawal
- **حجم الخط الافتراضي:** 16px (قابل للتعديل 12-24px)
- **الفئة CSS:** `.markdown-body` — تنسيقات خاصة لعناصر HTML المصيّرة

### عناصر مصيّرة خاصة
| العنصر | التنسيق |
|--------|---------|
| **العناوين (H1-H6)** | أحجام متدرجة، H1 بخط سميك وخط سفلي |

## 11. المستكشف الجانبي (Explorer Drawer)

- **العنصر:** `#explorer-drawer`
- **النوع:** `<aside>` — درج جانبي يُفتح من اليمين
- **العرض:** ~320-360px
- **الخلفية:** `var(--bg-surface-elevated)` مع `backdrop-filter: blur`
- **الانتقال:** `transform: translateX(100%)` → `translateX(0)` مع transition

### بنية المستكشف
```
┌─────────────────────────┐
│ 📁 المستكشف  [+📄][+📁][↻][×] │  ← الرأس مع أزرار
├─────────────────────────┤
│ 🔍 بحث في الفصول...      │  ← حقل بحث
├─────────────────────────┤
│ 📁 فصول الكتاب           │  ← شجرة مجلدات
│   📄 الفصل الأول         │     وملفات
│   📄 الفصل الثاني        │     (قابلة للسحب)
│ 📁 المسودات              │
│   📄 ملاحظات             │
│ 📁 الأرشيف               │
├─────────────────────────┤
│ 0 مجلدات • 0 ملف        │  ← إحصائيات
│ [تجميع الكتاب] [مطابقة]  │  ← أزرار إجراءات
└─────────────────────────┘
```

### أنماط عناصر الشجرة
- **المجلد:** أيقونة مجلد ملونة (#D97706 للمغلق، #F59E0B للمفتوح) + اسم + عدد الملفات
- **الملف:** أيقونة مستند + اسم + مؤشر نشط
- **الملف النشط:** خلفية `var(--accent-light)` مع حافة يمنى `var(--accent-color)`

## 14. الاستجابة (Responsive Design)

### نقاط الكسر (Breakpoints)
| النطاق | السلوك |
|--------|--------|
| **> 1024px** | عرض كامل: محرر + معاينة جنباً إلى جنب |
| **768px – 1024px** | شريط أدوات مضغوط، أزرار أصغر |
| **≤ 768px** | عرض تبويبي: إما محرر أو معاينة، شريط تبويبات سفلي |
| **≤ 480px** | تصغير إضافي للرأس وشريط الحالة |

### تعديلات الموبايل
- شريط الأدوات يصبح قابلاً للتمرير الأفقي
- شريط الحجرات يصبح قابلاً للتمرير
- أزرار الرأس تختصر (أيقونات فقط بدون نصوص)
- المستكشف يفتح بعرض كامل الشاشة
- النوافذ المنبثقة تأخذ عرض 95% بدلاً من 540px
