الدليل المعماري الشامل والنهائي لدمج الذكاء الاصطناعي في أي تطبيق ويب

المرجع الهندسي المتكامل: دمج Google Gemini API، تدوير المفاتيح، الـ Fallback الذكي، كود زر "إسأل AI" الفاخر (HTML + JSX + CSS)، مخططات Mermaid، عداد استيعاب المحتوى، والتمرير الذكي

أولاً: الفلسفة والدافع الهندسي (لماذا وكيف فكرنا بها؟)

في أغلب التطبيقات التقليدية، يقع المطور في إحدى مشكلتين عند إضافة الذكاء الاصطناعي:

  1. استنزاف ميزانية الخوادم (Server Cost Explosion): ربط التطبيق بخادم وسيط يدفع فيه المطور تكلفة كل سؤال يطرحه المستخدمون (API Quota Billing)، مما يؤدي للإفلاس السريع عند انتشار التطبيق.
  2. التعطل عند استنفاد الحصة أو انهيار النموذج: إذا توقف مفتاح الـ API أو كان النموذج تحت ضغط شديد، يتعطل التطبيق بالكامل وتظهر أخطاء مزعجة للمستخدم.

الحل المبتكر (Client-Side BYOK + Multi-Key Rotation + Smart Fallback):

  1. نموذج "أحضر مفتاحك معك" (Bring Your Own Key - BYOK): يدخل المستخدم مفتاحه المجاني من Google AI Studio (أو عدة مفاتيح)، وتبقى المفاتيح مشفرة ومحفوظة داخل جهازه فقط (Privacy-First) دون أي تكلفة على صاحب التطبيق.
  2. اعتماد gemini-3.5-flash-lite كنموذج افتراضي عالمي:
    • زمن استجابة شبه لحظي: يبدأ إرسال الردود في أقل من 500ms مقارنة بـ 4 ثوانٍ في النماذج الثقيلة.
    • حصص مجانية هائلة (High Free Quota): نادراً جداً ما يواجه خطأ 429 Too Many Requests.
    • توفير استهلاك التوكنز: صُمم خصيصاً للسرعة والإجابات المركزة المباشرة.
  3. مصفوفة الأمان الثلاثية (Triple-Safety Engine):
    • إن استنفد المفتاح حصته ⬅️ يتم تدوير المفاتيح تلقائياً في الخلفية.
    • إن كان النموذج غير متوفر في بلد المستخدم أو به عطل ⬅️ يسقط الكود تلقائياً للنموذج البديل.
    • إن أراد المستخدم تجربة نموذج آخر (مثل 3.8 Flash أو 2.5 Flash) ⬅️ يختاره من القائمة بكل حرية.

ثانياً: الشق المتعلق بالمنصات الخارجية (Google AI Studio Setup)

  1. إنشاء المفتاح من المنصة الرسمية:
    • الانتقال إلى Google AI Studio.
    • تسجيل الدخول بأي حساب Google شخصي مجاني، ثم الضغط على Get API key ثم Create API key.
  2. مزايا باقة Google AI Studio المجانية:
    • تمنحك جوجل حصة مجانية متجددة شهرياً وكافية لآلاف الأسئلة دون الحاجة لربط بطاقة ائتمان.
  3. تأمين الرابط وسياسة الاستخدام:
    • المفتاح يتم استدعاؤه مباشرة عبر الـ REST API من متصفح العميل إلى https://generativelanguage.googleapis.com.
    • لا يمر المفتاح بأي خادم وسيط على الإطلاق.

// lib/storage.js
import CryptoJS from 'crypto-js';

const ENCRYPTION_SALT = 'your-unique-app-secret-salt-2026';

export function encrypt(text) {
  if (!text) return '';
  return CryptoJS.AES.encrypt(text, ENCRYPTION_SALT).toString();
}

export function decrypt(ciphertext) {
  if (!ciphertext) return '';
  try {
    const bytes = CryptoJS.AES.decrypt(ciphertext, ENCRYPTION_SALT);
    return bytes.toString(CryptoJS.enc.Utf8);
  } catch {
    return '';
  }
}

export function saveGeminiKeys(keys) {
  if (typeof window === 'undefined') return;
  const encrypted = keys.map(k => encrypt(k.trim())).filter(Boolean);
  localStorage.setItem('app_gemini_keys', JSON.stringify(encrypted));
  window.dispatchEvent(new Event('storage'));
}

export function loadGeminiKeys() {
  if (typeof window === 'undefined') return [];
  try {
    const stored = localStorage.getItem('app_gemini_keys');
    if (!stored) return [];
    return JSON.parse(stored).map(k => decrypt(k)).filter(Boolean);
  } catch {
    return [];
  }
}

}

  if (typeof window === 'undefined') return;
  localStorage.setItem('app_active_key_index', String(index));
}

  if (typeof window === 'undefined') return;

}

  } catch {
    return [];
  }

الطبقة 2: محرك Gemini الذكي وضبط الردود "على قد السؤال" (gemini.js)

// lib/gemini.js
import { loadGeminiKeys, getCurrentKeyIndex, setCurrentKeyIndex, loadGeminiModel } from './storage';

const GEMINI_API_BASE = 'https://generativelanguage.googleapis.com/v1beta';
export const DEFAULT_GEMINI_MODEL = 'gemini-3.5-flash-lite';

const CANDIDATE_MODELS = [
  'gemini-3.5-flash-lite',
  'gemini-2.5-flash-lite',
  'gemini-2.0-flash-lite',
  'gemini-1.5-flash',
  'gemini-3.8-flash',
];

export async function callGemini(prompt, options = {}) {
  const keys = loadGeminiKeys();
  if (!keys.length) {
    throw new Error('يرجى إضافة مفتاح Gemini API في الإعدادات أولاً');
  }

  const preferredModel = options.model || loadGeminiModel() || DEFAULT_GEMINI_MODEL;
  const modelsToTry = [
    preferredModel,
    ...CANDIDATE_MODELS.filter(m => m !== preferredModel)
  ];

  const totalKeys = keys.length;
  const startIndex = getCurrentKeyIndex() % totalKeys;
  let lastError = null;

  for (let keyAttempt = 0; keyAttempt < totalKeys; keyAttempt++) {
    const keyIndex = (startIndex + keyAttempt) % totalKeys;
    const apiKey = keys[keyIndex];
    if (!apiKey) continue;

    setCurrentKeyIndex(keyIndex);

    for (const model of modelsToTry) {
      try {
        const url = `${GEMINI_API_BASE}/models/${model}:generateContent?key=${apiKey.trim()}`;
        const res = await fetch(url, {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          signal: options.signal,
          body: JSON.stringify({
            contents: [{ parts: [{ text: prompt }] }],
            generationConfig: {
              temperature: options.temperature || 0.65,
              maxOutputTokens: options.maxTokens || 3000,
            },
          }),
        });

        // 429 Quota Exceeded -> تدوير فوري للمفتاح التالي
        if (res.status === 429 || res.status === 403) {
          lastError = new Error(`المفتاح رقم ${keyIndex + 1} استنفد الحصة (${res.status})`);
          if (typeof window !== 'undefined') {
            window.dispatchEvent(new CustomEvent('gemini-key-rotated', {
              detail: { fromIndex: keyIndex, toIndex: (keyIndex + 1) % totalKeys }
            }));
          }
          break;
        }

        // 404 Model Not Found -> سقوط تلقائي للنموذج البديل
        if (!res.ok) {
          const errData = await res.json().catch(() => ({}));
          const errMsg = errData.error?.message || `خطأ ${res.status}`;
          if (res.status === 404 || errMsg.toLowerCase().includes('not found')) {
            lastError = new Error(errMsg);
            continue;
          }
          throw new Error(errMsg);
        }

        const data = await res.json();
        const text = data.candidates?.[0]?.content?.parts?.[0]?.text;
        if (!text) throw new Error('استجابة فارغة من النموذج');
        return text;

      } catch (err) {
        if (err.name === 'AbortError') throw new Error('تم إلغاء الطلب');
        lastError = err;
      }
    }
  }

  throw lastError || new Error('تعذر إتمام الطلب عبر كافة المفاتيح والنماذج');
}

export async function chatAboutItem({ item, history = [], newMessage, systemRole = 'مساعد تقني ذكي وخبير' }, options = {}) {
  const itemContext = JSON.stringify(item, null, 2);

  const systemPrompt = `أنت ${systemRole}.
أنت في محادثة مباشرة ونقاش تفاعلي مع المستخدم حول هذا العنصر بالتحديد:
${itemContext}

قواعد الرد والمحادثة الصارمة:
1. أجب مثل إنسان حقيقي خبير يقف أمام المستخدم: "على قد السؤال بالضبط".
2. إذا كان السؤال صغيراً أو مباشراً، أجب بجملة أو جملتين مركزتين دون مقدمات إنشائية أو إطالة مصطنعة.
3. تجنب كتابة صفحات أو فقرات طويلة أبداً، إلا إذا قال لك المستخدم صراحة: "اشرح بالتفصيل" أو "قارن بشكل شامل" أو طلب كوداً برمجياً كاملاً أو كانت الاجابة فعلياً تتطلب صفحات متعددة.
4. حافظ على نبرة واثقة، مباشرة، ذكية، ومريحة للقارئ.`;

  let fullPrompt = `${systemPrompt}\n\n--- سجل المحادثة السابقة ---\n`;
  for (const msg of history) {
    fullPrompt += `\n${msg.role === 'user' ? 'المستخدم' : 'AI'}: ${msg.content}\n`;
  }
  fullPrompt += `\nالمستخدم: ${newMessage}\n\nAI:`;

  return await callGemini(fullPrompt, options);
}

الطبقة 3: واجهة اختيار النماذج وإدارة المفاتيح (SettingsAiSection.jsx)

// components/SettingsAiSection.jsx
import { useState, useEffect } from 'react';
import { loadGeminiKeys, saveGeminiKeys, loadGeminiModel, saveGeminiModel } from '../lib/storage';

export default function SettingsAiSection() {
  const [keys, setKeys] = useState([]);
  const [newKey, setNewKey] = useState('');
  const [model, setModel] = useState('gemini-3.5-flash-lite');

  useEffect(() => {
    setKeys(loadGeminiKeys());
    setModel(loadGeminiModel());
  }, []);

  const handleAddKey = () => {
    if (!newKey.trim()) return;
    const updated = [...keys, newKey.trim()];
    setKeys(updated);
    saveGeminiKeys(updated);
    setNewKey('');
  };

  const handleRemoveKey = (idx) => {
    const updated = keys.filter((_, i) => i !== idx);
    setKeys(updated);
    saveGeminiKeys(updated);
  };

  const handleModelChange = (e) => {
    setModel(e.target.value);
    saveGeminiModel(e.target.value);
  };

  return (
    <div className="settings-card">
      <h3>إعدادات الذكاء الاصطناعي (Gemini AI)</h3>
      
      <div className="form-group">
        <label>نموذج الذكاء الاصطناعي:</label>
        <select value={model} onChange={handleModelChange} className="select-field">
          <option value="gemini-3.5-flash-lite">Gemini 3.5 Flash Lite (الموصى به - أسرع وأخف)</option>
          <option value="gemini-2.5-flash-lite">Gemini 2.5 Flash Lite</option>

  );

الطبقة 4: نافذة الشات التفاعلية المتطورة (UniversalAiChatModal.jsx)

// components/UniversalAiChatModal.jsx
import { useState, useEffect, useRef } from 'react';
import { chatAboutItem } from '../lib/gemini';
import { loadItemChat, saveItemChat } from '../lib/storage';
import { Sparkles, CheckCircle2, Loader2, Send, X } from 'lucide-react';

export default function UniversalAiChatModal({ 
  item, 
  isOpen, 
  onClose, 
  systemRole = 'مساعد ذكي وخبير',
  showQuickQuestions = false, // الخيار الأول: false افتراضياً لواجهة نظيفة
  quickQuestions = []
}) {
  const [messages, setMessages] = useState([]);
  const [input, setInput] = useState('');
  const [loading, setLoading] = useState(false);
  
  // الخيار الثاني: حالة فحص واستيعاب المحتوى والعداد
  const [isAbsorbing, setIsAbsorbing] = useState(false);
  const [absorbProgress, setAbsorbProgress] = useState(0);
  const [isAbsorbed, setIsAbsorbed] = useState(false);

  const inputRef = useRef(null);
  const chatBodyRef = useRef(null);
  const abortRef = useRef(null);
  const latestAiMsgRef = useRef(null);

  useEffect(() => {
    if (isOpen && item?.id) {
      setMessages(loadItemChat(item.id));
      setTimeout(() => inputRef.current?.focus(), 150);
    }
  }, [isOpen, item?.id]);

  const handleAbsorbContent = () => {
    setIsAbsorbing(true);
    setAbsorbProgress(0);

    const interval = setInterval(() => {
      setAbsorbProgress((prev) => {
        if (prev >= 100) {
          clearInterval(interval);
          setIsAbsorbing(false);
          setIsAbsorbed(true);
          return 100;
        }
        return prev + 25;
      });
    }, 200);
  };

  const handleSend = async (customPrompt) => {
    const text = (typeof customPrompt === 'string' ? customPrompt : input).trim();
    if (!text || loading) return;

    const userMsg = { 
      role: 'user', 
      content: text, 
      time: new Date().toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' }) 
    };
    const newHistory = [...messages, userMsg];
    setMessages(newHistory);
    saveItemChat(item.id, newHistory);
    setInput('');
    setLoading(true);

    const controller = new AbortController();
    abortRef.current = controller;

    try {
      const reply = await chatAboutItem({
        item,
        history: messages,
        newMessage: text,
        systemRole
      }, { signal: controller.signal });

      const aiMsg = { 
        role: 'model', 
        content: reply, 
        time: new Date().toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' }),
        id: `ai-${Date.now()}`
      };
      
      const updated = [...newHistory, aiMsg];
      setMessages(updated);
      saveItemChat(item.id, updated);

      // ميزة السكرول الذكي: التمرير فوراً إلى أول سطر في رد الـ AI إذا كان الرد طويلاً
      setTimeout(() => {
        if (latestAiMsgRef.current) {
          latestAiMsgRef.current.scrollIntoView({ behavior: 'smooth', block: 'start' });
        }
      }, 100);

    } catch (err) {
      const errMsg = { role: 'model', content: `⚠️ تعذر استلام الرد: ${err.message}`, isError: true };
      setMessages([...newHistory, errMsg]);
    } finally {
      setLoading(false);
      abortRef.current = null;
    }
  };

  if (!isOpen || !item) return null;

  return (
    <div className="modal-overlay" onClick={onClose}>
      <div className="modal-content chat-modal-premium" onClick={(e) => e.stopPropagation()}>
        
        {/* رأس النافذة */}
        <div className="modal-header">
          <div className="chat-header-title">
            <span className="chat-badge-icon">💬</span>
            <div>
              <h3>{item.title || item.name}</h3>
              <p className="chat-subtitle">محادثة تفاعلية مباشرة مع الذكاء الاصطناعي</p>
            </div>
          </div>
          <button onClick={onClose} className="btn-close-modal">✕</button>
        </div>

        {/* الخيار الثاني: منطقة فحص وقراءة المحتوى */}
        <div className="content-absorption-bar">
          {!isAbsorbed && !isAbsorbing && (
            <button onClick={handleAbsorbContent} className="btn-absorb-trigger">
              <Sparkles size={16} />
              <span>فحص وقراءة تفاصيل المحتوى للبدء</span>
            </button>
          )}

          {isAbsorbing && (
            <div className="absorb-progress-wrapper">
              <div className="absorb-progress-header">
                <span className="pulse-dot"></span>
                <span>جاري فحص وقراءة بيانات المحتوى... {absorbProgress}%</span>
              </div>
              <div className="absorb-progress-track">
                <div className="absorb-progress-fill" style={{ width: `${absorbProgress}%` }}></div>
              </div>
            </div>
          )}

          {isAbsorbed && (
            <div className="absorb-success-banner">
              <CheckCircle2 size={18} className="text-emerald" />
              <span>تم فحص واستيعاب كامل المحتوى بنجاح — أنا جاهز لإجابتك على قدر السؤال بدقة!</span>
            </div>
          )}
        </div>

        {/* الأسئلة المقترحة إن رغب المطور بتفعيلها */}
        {showQuickQuestions && quickQuestions.length > 0 && messages.length === 0 && (
          <div className="quick-questions">
            {quickQuestions.map((q, i) => (
              <button key={i} onClick={() => handleSend(q.text)} className="quick-btn">
                {q.label}
              </button>
            ))}
          </div>
        )}

        {/* جسم الشات */}
        <div className="chat-messages-container" ref={chatBodyRef}>
          {messages.length === 0 && !loading && (
            <div className="empty-chat-state">
              <div className="empty-icon">🤖</div>
              <h4>تفضل بطرح سؤالك حول هذا المحتوى</h4>
              <p>سأجيبك باقتضاب وسرعة على قدر سؤالك تماماً دون حشو أو إطالة.</p>
            </div>
          )}

          {messages.map((m, idx) => {
            const isLastAi = m.role === 'model' && idx === messages.length - 1;
            return (
              <div 
                key={idx} 
                ref={isLastAi ? latestAiMsgRef : null}
                className={`chat-bubble-row ${m.role === 'user' ? 'row-user' : 'row-ai'}`}
              >
                <div className={`chat-bubble ${m.role === 'user' ? 'bubble-user' : 'bubble-ai'} ${m.isError ? 'bubble-error' : ''}`}>
                  <div className="bubble-text">{m.content}</div>
                  <span className="bubble-time">{m.time}</span>
                </div>
              </div>
            );
          })}

          {loading && (
            <div className="chat-bubble-row row-ai">
              <div className="chat-bubble bubble-ai bubble-typing">
                <Loader2 size={16} className="animate-spin" />
                <span>جاري صياغة الرد المركز...</span>
              </div>
            </div>
          )}
        </div>

        {/* شريط الإدخال */}
        <div className="chat-input-bar">
          <input 
            ref={inputRef}
            type="text" 
            placeholder="اكتب سؤالك هنا باختصار..." 
            value={input} 
            onChange={(e) => setInput(e.target.value)}
            onKeyDown={(e) => e.key === 'Enter' && handleSend()}
            disabled={loading}
          />
          <button onClick={handleSend} disabled={loading || !input.trim()} className="btn-send-chat">
            <Send size={16} />
          </button>
        </div>

      </div>
    </div>
  );
}

ملاحظات:

🔹 الواجهة النظيفة الفورية (بدون أي أسئلة مقترحة)

عند فتح نافذة الشات، لا تظهر أي أسئلة مقترحة تملأ الشاشة أو تشتت الانتباه. بل تظهر نافذة نظيفة هادئة تحتوي على اسم العنصر، مع التركيز الفوري للمؤشر في حقل الكتابة ليطرح المستخدم ما يريده مباشرة.

🔹ميزة "قراءة واستيعاب المحتوى" (Content Scan & Absorb)

زر تفاعلي مخصص اختياري: [ قراءة واستيعاب تفاصيل المحتوى]

  • كيف يعمل العداد؟
    عند النقر عليه، يعمل مؤشر تقدم رسومي (Progress Bar من 0% إلى 100%) مصحوباً بنبض مرئي (Pulse Animation) لمدة ثانية أو ثانيتين يقوم خلالها النظام بفحص كائن المحتوى.
  • شارة التأكيد الخضراء المتوهجة:
    فور انتهاء العداد بنسبة 100%، يختفي الزر وتظهر شارة دائمة راقية:
    تم فحص واستيعاب كافة تفاصيل المحتوى بنجاح! أنا الآن جاهز للإجابة عن أي استفسار بخصوصه.
    هذه الشارة تمنح المستخدم اطمئناناً وثقة كاملة بأن الذكاء الاصطناعي قد قرأ وألم بكافة التفاصيل.

🔹 ميزة السكرول الذكي التلقائي لأعلى الرد (Auto-Scroll to Top of Response)

في غرف الشات العادية، السكرول دائماً ينزل إلى أسفل الصفحة (scrollIntoView: end)، وبالتالي إذا كتب الذكاء الاصطناعي رداً طويلاً، فإن المستخدم يجد نفسه ينظر إلى آخر سطر في الرد، ويضطر يدوياً للبحث والتمرير للأعلى لمعرفة من أين بدأت الإجابة!

  • الحل البرمجي المنفذ:
    عند اكتمال الرد، يقوم الكود برصد بداية الفقرة التي كتبها الـ AI (#ai-response-${index}) وعمل تمرير سلس مباشر إلى أول سطر من الرد (block: 'start')، ليجد المستخدم نفسه يقرأ من البداية فوراً.
